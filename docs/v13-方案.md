## 0. 取证（先证明根因，再动代码）

### 0.1 bug (a)「新建子文件夹没用、创建不了」——真凶是「搬进自己内部」的无限复制

面板原来的「新建子文件夹」把 `dir` 拼成 **`<当前房间目录>\<新名字>`**，也就是**把房间目录改成它自己的子目录**。宿主 `PATCH /rooms/:id {dir}` 原本会「`mkdir` + 把旧目录整体搬过去」，而 `moveDir` 在目标已存在时走 `mergeDirInto(from, to)`；此时 `to` 是 `from` 的祖先 ⇒ **边读边写自己的新副本**，无限套娃。

用临时探针（真机同形：root=`<tmp>\root`、category=`<tmp>\cat\会议`、房间 `main`）实测：

| 请求 | 结果 |
| --- | --- |
| `PATCH { dir: <房间目录>\素材\v2 }` | **6 秒不返回**（请求挂住，目录开始套娃） |
| `PATCH { dir: <房间目录>\存档\layer2 }`（目标已存在） | 6 秒不返回，宿主 warn 抛 `ENOTEMPTY: directory not empty, rmdir '…\会议\main\存档\layer2\存档\layer2\存档\layer2\…'`（套了几百层） |
| `PATCH { dir: <分类目录>\新目录 }`（同级、不存在） | **200**，`room.dir` 正常切换 ⇒ 同级新建本身是好的 |

放大链条：复制出来的子目录里也带着一份 `room.json`，旧 `isRoomDataDir` 只比对 `meta.id === room.id` ⇒ 那个子目录又被认成「本房间数据目录」，下一次 PATCH 再搬一次。

### 0.2 bug (b)(c) 的症状与判定

- (b)「解散会议后与会 AI 依然在对话」：`room_say` 与人类 `POST /rooms/:id/post` 两条通路**都不看房间状态**，散会之后照样广播/自动接力（`autoHop` 也照样自增）⇒ 链子被重新点起来。
- (c)「临时文件直接出现在桌面」：插件里 **grep 不到** `mkdtemp` / `tmpdir` / `.tmp` 任何创建点 ⇒ 文件不是插件写的，而是**与会者会话的 cwd 就是桌面**（用户桌面新出现的 `实验*`、`v12-审计报告*.md` 等正是与会者 AI 不带路径写文件的产物）。所以正确的修法是「在唤醒消息里把落盘位置讲清楚」，而不是加清理器。

### 0.3 消息索引：DSH 侧反查结论（穷尽后改为自实现）

## 1. 任务① + bug(a)：会议文件夹「默认 + 可改」，新建/选择 = 整个房间搬进去

### 1.1 宿主：换目录前的整体安全闸（新增 `moveTargetReason`）

```js
// index.js:1312（新增，只在 PATCH /rooms/:id {dir} 用）
async moveTargetReason(room, nextDir) {
  const target = resolve(String(nextDir ?? '').trim() || '.');
  const prev = resolve(room.dir);
  if (samePath(target, prev)) return null;                       // 同一个目录：调用方本来就会跳过
  if (insidePath(target, prev)) {
    return `不能把会议文件目录改成它自己的子目录（${target}）：房间文件会被无限复制。请选一个同级的新文件夹。`;
  }
  if (samePath(target, resolve(this.defaultCategory)) || samePath(target, resolve(this.settings?.category ?? this.defaultCategory))) {
    return `不能把会议文件目录改成分类目录本身（${target}）：那样各房间的文件会混在一起。请在分类目录下新建一个子目录。`;
  }
  return null;
}
```

- `PATCH /rooms/:id {dir}` 在 `assertSafeRealTarget` 之后插入 `const blocked = await host.moveTargetReason(room, nextDir); if (blocked) throw fail(400, blocked);`（`index.js:2324`）。
- `moveDir` 顶部加自保：`if (insidePath(to, from)) return false;`（`index.js:288`，注释写明「否则合并复制会边写边读自己的新副本」）。
- `isRoomDataDir` **保持原样**（只 `meta.id === room.id`）：曾试过再加「目录名必须还是房间 id」，会弄坏 F2/F4「目录名 ≠ 房间 id」的合法用例，已回退 —— 认目录名不是这里该干的事，形状由 `moveTargetReason` 在换目录**之前**拦。

### 1.2 客户端：「新建子文件夹 / 选择已有文件夹」都拼 `<父目录>\<名字>\<房间id>`

```js
// client/client.js:518（新增小工具；用字符串相加，便于自测逐字断言）
function joinPath(base, name) {
  const head = String(base || '').replace(/[\\/]+$/, '');
  const tail = String(name || '').replace(/^[\\/]+/, '');
  if (!head) return tail;
  if (!tail) return head;
  return head + '\\' + tail;
}
```

- 「新建子文件夹」：`const picked = joinPath(joinPath(parent, name), roomId); await patchJson(\`/rooms/${q(roomId)}\`, { dir: picked });`，成功文案「已把会议文件目录搬到新建的文件夹里」。
- 「选择已有文件夹」（复用已有 `DirPicker`）：`value: parent`、`pickLabel: '把会议会议室放到这个文件夹里'`、`onPick: (picked) => PATCH { dir: joinPath(picked, roomId) }`。
- 文案同步：「本次会议的文件目录：…」+ 尾部说明「新建/选择文件夹会把整个房间一起搬过去」。
- **没有新增端点、没有新增配置项、没有新增面板控件**（`PATCH {dir}` 原本就会 `mkdir` 并整体搬目录）。

## 4. 任务③：自动下拉（照 DSH `ScrollFollow` 的语义重写）

参考 `dsh-client-ui-chat/lib/client.js` 的 `ScrollFollow` 类（字段 `following` / `threshold` / `target` / `sampledTop`，方法 `nearBottom` / `sample` / `settle` / `jump` / `toBottom`），会议室客户端只取四件事（不装 `IntersectionObserver`，DSH 全仓也没用）：

1. **跟随意图** `following`（缺省 true）+ 阈值 **25px**；
2. **只有「读的人自己滚」才改变跟随意图**：`onScroll` 里 `if (Date.now() - programmatic.current < 800) return;` —— 程序化滚动（自己刚发完消息 / 新消息到达）不算用户滚动；
3. 记录**变长**时：跟随中就 `toBottom`，没跟随就只挂 `hasNew`（**不打断用户往回翻**）；
4. 不跟随时显示一个 **「↓ 跳到最新」** 按钮，点了恢复跟随并平滑滚到底（`el.scrollTo({ top: el.scrollHeight, behavior: 'smooth' })`）。

实现落点（`client/client.js`）：`toBottom(smooth)`（`:1366`）、跟随意图与 `onScroll`（`:1370-1380`）、唯一的跟随 effect（`:1385-1395`）、滚动容器 `'data-scroll': 'log'`（`:1490`）、「跳到最新」按钮（`:1518-1521`）。`S.scrollFollowing` 对应 DSH 的 `[data-chat-following-tail]`，给滚动口加 `overflowAnchor: 'none'`，避免新内容把阅读位置顶走。

## 7. 诚实边界

- **需重载/重启 DSH 才在真机生效**（本机插件目录是 Junction 指回源码目录；盘上已经是 v13 代码，但跑着的进程仍是旧版）。截至写下这段时没有重启过 DSH。
- 索引是**按消息量**排条：消息很多时横线密集（截图里的普通会话也是这个形态）；不做聚合/分组，**没有**新增面板控件或配置项。
- 自动下拉**不妨碍往回翻**：用户自己滚动即停跟随，之后新消息只提示「有新消息」，要回去点「↓ 跳到最新」。
- bug(c) 是**文案级**修法：把落盘位置告诉与会 AI。若某个与会者会话仍然写桌面，那是它没有按提示写 —— 插件不替它搬文件（不新增定时清理/回收逻辑，符合最小变动）。
- 会议文件夹可改的语义是**整体搬移房间**（`<分类目录>\<新文件夹>\<房间id>`），所以搬完旧路径就不存在了；「搬到分类目录本身」与「搬进自己的子目录」由宿主直接 400 拒绝（中文原因）。
