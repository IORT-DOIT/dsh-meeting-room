## 1. 一句话定位

**一句话：** 把 DSH 里一个又一个会话，变成一个真正的会议室 —— 多个 AI（和你在内）围着同一个目标讨论、交接文件，目标达成自动出《会议结果》，你只负责拍板。

**三行版：**

- 一个侧边栏入口，多间会议室，每间自带会议目标、会议记录、附件夹和一位**内置记录员**。
- 与会者 AI 用 `room_*` 工具发言、读记录、交文件、汇报进展；你一发言，讨论自己往下走，不会「答完一轮就静止」。
- 定稿不靠谁转述：记录员读完**完整记录**写草稿，**你审核后**才按成员分节发布。

**slogan 备选：**
1. 多个 AI，一张会议桌。
2. 讨论留在会议室，结论交到你手上。
3. 你只开会和拍板，其余交给会议室。

## 3. 社区发帖主文案（可直接贴）

### 标题候选

1. **【插件】会议室：让多个 AI 在同一个目标下讨论、出结论（DSH / v18）**
2. **【插件】dsh-meeting-room：多个会话，一张会议桌**
3. **【插件】给 DSH 加一个会议室 —— 多 AI 协作、自动出《会议结果》**

### 正文

**你有没有这样用过 DSH：** 开三个会话，各自问一遍；再把 A 的结论复制给 B 看，改了之后再贴回 A；最后自己当人肉总线，把散落在四个窗口里的意见抄成一份总结。会话越多，你越像一台路由器。

**会议室这个插件，就是把这件事变成「开会」。**

侧边栏多一个「会议室」入口。里面可以建多间会议室，每间有：

- **一个会议目标**（同时只有一个在进行，达成后自动推进下一个）；
- **一份会议记录**（追加写入，AI 与你看到的是同一份）；
- **一个自己的文件夹**（`记录/` 放记录与结果，`附件/` 放讨论产物）；
- **一位内置记录员** —— 讨论出结果时，它会读完**完整记录**写一份《会议结果》草稿。

把已有的会话（AI 会话、或者你自己）加进房间当「与会者」，它们就多了 13 个工具：`room_say` 发言、`room_read` 读记录、`room_files`/`room_open` 交接文件、`room_goal_report` 汇报目标是否达成、`room_task_done` 宣布收尾……你在面板里看到的，和 AI 在工具里操作的是**同一份记录**。

### 它解决的六个具体痛点

**1. 讨论不会「答完一轮就静止」。**
缺省的 `room_say` = 写进记录 **+ 自动接力**：插件给其他与会者各投一条提示（**只提醒，不含任何正文**），他们自己来读记录、接着讨论。接力**没有跳数上限**，一直接到没人有话说为止；你发言也会把节奏重新带起来。

**2. 你的话不会被塞进 AI 的对话里。**
这是**结构性**保证，不是提示词承诺：投递接口只接受 `archive`（只记录）和 `notice`（只提醒一句「有 N 条新消息」）两种口径，传 `full` 也会被**降级**成那句不含正文的提示 —— 正文**永远不进入与会者对话**。（与会者之间互相投递不受这条限制；你要让某位与会者读到具体内容，就在它自己的会话里说，或让另一位与会者用 `room_say` 的全文档转述。）会议室是群聊，但你的麦克风默认只接记录仪。

**3. 结论不是你抄的，而是记录员读完整记录写的。**
目标被标记达成（你点「标记达成」，或与会者用 `room_task_done` 发一条「任务完成」指令）→ **记录员立即产出草稿** → 你在右侧「会议结果」常驻栏里看全文、改、通过或驳回；与会者还能用 `room_goal_report` 汇报「达成 / 有分歧」。记录员的提示词明确写着：只记最终共识、分工与待办，不写过程与辩驳，**不得编造、不替任何一方补观点**。驳回也不是一句话打发 —— 插件会把「草稿被驳回 + 会议目标 + 驳回原因 + 逐条回应」整套投给全体，让他们立刻重议。

**4. 会议文件真的会进会议文件夹。**
与会者会话的工作区往往就是你的桌面，一句「请写到会议室文件夹」根本管不住（实测无效）。所以这件事做了三层兜底：与会者 agent 作用域的**影子文件工具**改写顶层路径 → 投递即开窗 + 工具执行后 + 轮次结束的**快照差集**（连 `pwsh` 写的文件也认）→ 不依赖任何钩子的**巡检**（在交作业与每次唤醒前按时间收拢）。规则克制：**只搬本轮新建的文件**、改你既有文件只取副本、**首次只立基线**。打开房间的「附件/」，产物就在里面。

**5. 权限申请在会议室里直接批。**
与会者要写文件、要提权时，请求会以横幅形式出现在会议室面板上：**允许 / 拒绝**，不用切到它的会话页去点。（细节：允许是一次性的 `allowed-once`；非与会者、超时 120 秒、对方取消，一律交回 DSH 原来的审批链。）为这件事还专门查过一个真机 bug —— DSH 转发审批给浏览器的桥注册得更早且会阻塞，普通监听永远轮不到；现在用 `prepend` 插到它前面，只有本房间成员会被接管。

**6. 用起来像 DSH 原生，不像外挂。**
颜色全用官方主题 token；消息索引做成一**轮**一刻度、悬浮在右侧，会议目标那个时间点**加粗变色**；聊天气泡、自动跟随滚动照 DSH `ScrollFollow` 的语义（你自己滚就停跟随，不打断你往回翻）；输入框下方一条数据条显示**轮次 / 步 / token / 缓存命中 / 上下文占用**（拿不到数据就整条不渲染，不给你看假数字）。

### 为什么它值得放心装

- **工具 13 个、配置键 8 个（默认全部可用）、只往宿主上挂三样东西**：一个 `/dsh-room` 路由、一组 `room_*` 工具、一个客户端面板。**不替换 DSH 任何内置能力**，不碰宿主配置。
- **数据完全在你自己的目录里**：状态根 `~/.dsh/meeting-room` 与会议目录（默认 `~/dsh/会议`）。**删掉目录 = 删掉会议**，没有隐藏状态。
- **只服务本机回环**：端点校验 `Host`/`Origin`，跨站来源直接 403；插件只写自己的目录，目录护栏折叠大小写、解析软链 / junction / 8.3 短名、按文件身份判等。
- **525 项自动化自测全绿**（12 秒跑完，`PASS 无未处理的 Promise 拒绝`）。版本一路从 0.1 走到 **0.18.0**，几乎每一版都是被真机问题逼出来的：NTFS 大 inode 误判、聊天页被弹回、`signal timed out`、新建文件夹无限复制、桌面文件收不进去、与会者「排队消息」堆积、审批弹错地方……都留在 `docs/v*-方案.md` 里，含取证过程与诚实边界（包括「这条只在什么条件下才生效」）。
- **排障有只读诊断**：`GET /dsh-room/staging` 一次看清影子工具注册状态、每个成员的守则/暂存情况、文件搬运流水、审批监听状态。

### 适合谁

- 同时开多个会话做**并行调研 / 方案对比 / 代码评审**，最后要一份统一结论的人；
- 用 AI **写长篇**（分章分节、多人设分工）需要一个共享工作区与统一记录的人；
- 想让**多个不同模型的会话互相质证**，而不是自己来回转述的人；
- 做 agent 协作 / 多智能体实验，想要**可读记录 + 可审结论 + 可查文件**，而不是黑盒的人。

### 安装（三步）

```
install_bundle link:<你的路径>/dsh-meeting-room
```

装完**重启 DSH**（或让 profile 重新加载）→ 侧边栏出现「会议室」→ 建房间、把会话加进去、写会议目标。

兜底与卸载见仓库 README §3；配置键（状态根 / 会议目录 / 默认房间 / 读取上限 / 自动接力开关）见 §8。

## 5. English version (for the GitHub landing page)

### dsh-meeting-room — many sessions, one meeting table

A **meeting-room** plugin for [DSH](https://github.com/) (DeepSeek Harness): multiple sessions — AIs and humans — discuss one shared goal, hand files over, and write one shared transcript. When a goal is reached, the room's **built-in recorder** reads the whole transcript and drafts the final resolution, which is published **only after your review**.

**What you get**

- **Rooms with goals, records and folders.** One sidebar entry; every room keeps a serial goal list, an append-only transcript (`transcript.jsonl` + human-readable `transcript.md`), and its own folder (`记录/` for records, `附件/` for deliverables).
- **A built-in recorder per room.** No assignment, no configuration: when a goal is marked done (by you, or by a member's `room_task_done` instruction), the recorder drafts the resolution immediately — consensus, owners and TODOs only, no invented content.
- **Auto-relay, no hop limit.** A member's default `room_say` writes to the record *and* pings the other members to come and respond, so the discussion keeps moving instead of stopping after one round.
- **Your words never enter their conversations.** Delivery accepts only `archive` (record only) or `notice` (a one-line "new message" ping); a `full` request is downgraded to that notice, so your text never reaches a participant's context. (Direct, body-carrying delivery between participants is still available to them.)
- **Files actually land in the room folder.** Three fallback layers (per-agent tool shadows, post-execute/turn-stopping snapshots, hook-free sweeps) collect what participants write, including files created via `pwsh`. Only files created in the current round are moved; edited files are copied; a baseline protects everything older.
- **Approve tool permissions in the room.** Requests appear as an allow/deny banner in the room panel instead of a dialog in the participant's session (one-time `allowed-once`; non-members, timeouts and cancellations fall back to DSH's original approval chain).
- **Native-feeling UI.** Official theme tokens, a turn-based message rail with the goal marker highlighted, DSH-compatible scroll-following, and a stats bar for turns / steps / tokens / cache hit / context usage.

**Engineering notes**

- 13 `room_*` tools, 8 config keys (defaults work as-is), three mount points (a `/dsh-room` route, the tools, one client panel). Nothing in DSH is replaced.
- All data lives in your own directories (`~/.dsh/meeting-room` and the meeting folder). Delete the folder, delete the meetings.
- Loopback-only endpoints with `Host`/`Origin` checks; the plugin only writes its own directories, with real-path/short-name/case-folding guards.
- **525 automated self-test assertions pass** (about 12 seconds), across 18 releases; every version's investigation and honest limitations are documented in `docs/v*-方案.md`.

**Install**

```
install_bundle link:/path/to/dsh-meeting-room
```

Restart DSH, then create a room, add sessions as participants, and set a goal.
