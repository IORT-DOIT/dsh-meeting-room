## 2. 设计

### 2.1 宿主：新增只读预览端点 `GET /rooms/:id/file?name=`
- 回包：`{name, bytes, mime, kind:'text'|'binary', truncated?, text?}`。
- 校验顺序：缺 `name` → 400「name 必填」；`roomFilePath` 返回 null（穿越 / 绝对路径 / 非法名）→ 400「非法文件名」；不存在 → 404「文件不存在：X」。
- 文本判定 `isTextualFile(base, mime)`：扩展名在白名单（`.md .txt .json .csv .html .htm .xml .yml .yaml .log .js .mjs .cjs .ts .tsx .jsx .css .py .sh .ps1 .bat .ini .toml .sql .c .h .cpp .java .go .rs .rb .php .vue .diff .patch`）或 mime 是 `text/*` / json / xml / javascript。
- 二进制**不回** `text` 字段（避免把图片塞进 JSON）。
- 超过 `PREVIEW_MAX_BYTES = 128 * 1024`：只读前 128 KB，`truncated:true`，尾部残缺 UTF-8 只去掉替换符（不编造内容）。
- 全程只读：不写 `room.json`、不改文件、不动 mtime。
- 老路径兼容：`:2602` 的已知端点集合加 `'file'`。

### 2.2 客户端：左侧保持原样 + 右侧常驻栏
- 外层容器 `S.cols`（row）；左列仍是原来的 `S.root`（加 `flex:1 1 auto; min-width:0`）；右栏 `RoomSide` 宽 300、`borderLeft`、底色 `SIDEBAR_FILL`。
- 右栏 = 栏头（页签「会议文件 (n)」/「会议结果 (m)」+ 右侧「收起」）+ 栏体。
  - 文件页签：文件列表（名 + `byteSize`，点选即取 `/rooms/:id/file?name=` 并在下方 `S.preview` 里 `<pre>` 显示正文）+ 「原文件」链接（保留原来的新标签页下载能力）；加载中 / 读取失败 / 二进制（提示不能预览，只给链接）三种状态各有文案。
  - 结果页签：把聊天区那个内联盒整块搬进来，按钮文案与回调逐字不变（看全文 → 现有 `openResult`；通过并发布；驳回 → 现有自绘对话框）。
- 页头：`会议文件` 按钮（切到文件页签 + 展开右侧栏）、新增 `会议结果` 按钮（切到结果页签 + 展开右侧栏）、末尾新增「收起侧栏 / 展开侧栏」开关（`view.sideOpen`）。
- `newView()`：删 `filesOpen`，加 `sideOpen:true`、`sideTab:'files'`、`fileSel:''`、`preview:null`（预览内容只存内存、不落盘）。
- 删除 `FilesDrawer`（能力已搬进右栏）。
- 轮询不重取预览：只在点文件名时取一次；`refreshAll` 不清 `preview`。
